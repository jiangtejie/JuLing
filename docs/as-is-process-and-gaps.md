# 亚特餐饮集团现状流程（CY-001）→ 本系统落点与差距

> 来源：用户提供的两张图与业务背景 ——
> ① 《CY-001 重庆亚特餐饮整体业务流程》泳道图（移动端订货 / 星空企业版-中心库 / 星空旗舰版-营业收入云 / 美团）；
> ② 集团组织架构图（重庆亚特餐饮发展有限公司 → 卤校长(公司) / 中心库 / 萍姐(公司) / 直营门店）。
>
> 业务背景（原文）：门店前端营业收银系统与供应链系统为**美团**，财务系统与费用报销系统为**金蝶**；
> 集团**多品牌**，门店订配业务**品牌之间分离**，**业财分离**。目标：多品牌门店（直营/加盟）订配业务、
> 对直营/加盟门店强管控、保障库存资源合理分配；提高订配业务高效运转；强管控门店库存与食品成本；
> 统一规范库存管理、共享库存信息、统筹调度，实现库存最优化。
>
> 相关设计：store-ordering-flow-design.md、organization-model.md、kingdee-gap-requirements.md。

## 2. 关键规则（图上明确了、设计里要改的）

1. **审核分流（对 S1 的修正）**：图上写明"加盟门店需财务审核进入订单工作台 / 直营门店则直接审核"。
   即审核闸门**只对加盟店**（资金风险），直营店直接流转。S1 现在是无差别提交 BPM 供应链审核，
   需要改成：店型 = 加盟（FRANCHISE）→ 财务审核；店型 = 直营（DIRECT）→ 直接可发货。
   亚特的 erp_customer.store_type 字段已在 S1 建好，直接可用。
2. **分料属性（统配 / 直配）**：这是中心库分支的判断条件，也是"库存最优分配"的抓手。建议落成
   **订单行级**属性（同一张要货单可能既有统配品又有直配品，需拆成两张出库/采购单据）：
   统配 = 中心库配送出库 → 门店收货；直配 = 中心库采购订单 → 供应商直送门店 → 采购入库（入库仓 = 门店）+ 应付。
3. **订单工作台 = 中心库的操作中枢**：要货申请不直接变出库单，而是先在工作台完成分料判定、改量拆单、
   指定收货仓、区分统配/直配，再下推。这是"统筹调度、库存最优化"的落点。
4. **多品牌 + 品牌间订配分离**：组织架构图与库里部门树一致（萍姐/卤校长/直营门店/中心库 四支）。
   品牌分离应体现为**按品牌（部门分支）隔离的订货范围与库存可见性**，而不是多租户（见组织模型）。
5. **业财分离**：营收/收银在美团、财务在金蝶，本系统要替代的是**订配与库存管控**这一段，
   并把结果（销售清单、领料、报损、记账单）推给财务 —— 即 FMS 凭证自动化按这条链设计。

## 3. 目标 → 系统能力对照（验收口径）

| 集团目标 | 系统能力 | 归属阶段 |
|---|---|---|
| 多品牌门店（直营/加盟）订配业务 | 一店三面 + 代理商多门店 + 品牌隔离 + 直营/加盟分流审核 | S1 已完成（品牌隔离与分流审核待补）|
| 对直营/加盟门店强管控 | 账期/信用/余款 + 审核闸门 + 配送价管控 + 门店库存与报损管控 | S1（闸门已有）+ S3/S4 |
| 保障库存资源合理分配 | 订单工作台分料 + 可用量（在仓 − 占用 + 在途）+ 按提交先后分配 + 缺货登记 | S2 |
| 提高订配业务高效运转 | 订单工作台一键下推 + 统配/直配自动分流 + 待办提醒 | S2 |
| 强管控门店库存、食品成本 | 门店库存账 + 盘点/盘亏/报损 + 食材销售清单 + 成本核算 | S4 及后续 |
| 统一规范库存管理、共享库存信息、统筹调度 | 中心库 + 门店 + 三方仓统一库存口径（含在途/占用/待检）| S2 + WMS 对接 |

## 5. 待确认（影响 S1 收尾与 S2 设计）

1. **审核人是谁**：图上写"加盟门店需财务审核"。是①财务审核（资金/账期）后进订单工作台（工作台不再审批），
   还是②财务 + 供应链两级审核？（决定 S1 的 BPM 审批节点配置）
2. **直营门店是否完全免审**（收款核验后直接可发货），还是仍需供应链确认数量与库存？
3. **门店自采（门店采购订单/入库）**是否纳入本期范围（涉及应付归属与报销，与付款对账需求相关）？
4. 直配的**入库仓**记为门店还是中心库（影响库存账与成本归属）？
